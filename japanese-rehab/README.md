# 日文復健學習系統

個人用的日文復健工具：自動接續進度、短句輸出、精準訂正、PASS 判定與學習紀錄。
純 Python 3 標準函式庫，**不需要安裝任何套件**（Python 3.9+）。

## 快速開始

```bash
cd japanese-rehab
python3 jp.py init        # 第一次：用目前的學習紀錄建立進度檔（已建立過會略過）
python3 jp.py             # 開始今天的練習（等同 python3 jp.py today）
python3 jp.py dashboard   # 看儀表板
```

作答時：`?` 看提示（該題不算獨立輸出）、`s` 跳過、`q` 結束（已作答的題目都已存檔）。

## 指令

| 指令 | 說明 |
|---|---|
| `jp.py today [--mode M] [--grammar ID] [--scenario S] [-n 3] [--no-ai]` | 今天的練習，自動從上次進度接續 |
| `jp.py dashboard` | 已學／PASS／未學數量、進行中文法、常見錯誤、最近紀錄、下一堂建議 |
| `jp.py grammar [ID] [--status pass\|learning\|needs_work\|not_started]` | 文法清單或單一文法詳細內容 |
| `jp.py errors` | 錯誤追蹤（尚未改正／已改正一次／穩定掌握） |
| `jp.py history [--limit N]` | 最近的題目、你的答案、修正版與錯誤類型 |
| `jp.py set-status ID STATUS` | 手動調整狀態（例如你認為某項該重練） |
| `jp.py init --reset` | 用初始資料重設進度（舊檔留成 `.bak`） |

練習模式 `--mode`：`full`（完整流程，預設）、`review`（只看範例）、`dialogue`（情境對話）、
`translate`（中翻日）、`compose`（自行造句）、`mixed`（綜合，混用舊文法）、`correction`（錯誤補強，以活用練習為主）。
情境 `--scenario`：`work food shopping leisure travel friends health daily`。

## 一堂課的流程（對應規格的 Step 1–7）

1. **確認進度**：讀 `progress.json` 與 `history.jsonl`，顯示主要文法、追蹤中的錯誤、距離 PASS 還缺什麼。
2. **範例複習**：意思、接續、2–4 個例句（日文＋假名＋繁中）、常見錯誤、易混淆句型。
3. **情境對話**：該文法有對話時顯示（工作、飲食…，不固定旅行）。
4. **短句輸出**：先一題舊文法暖身（若有尚未穩定的錯誤）→ 活用練習（只在該文法有未穩定的活用／接續錯誤時）→ 2–3 題造句／中翻日。
5. **訂正**：原句、修正版、錯誤類型與原因、更自然的說法。活用練習答錯會立刻補一題同類型題目。
6. **PASS 判定** 與 7. **更新紀錄**：每題作答後立即存檔；課程結束寫入 session 摘要與「下次從這裡開始」。

## 選擇哪個文法（`scheduler.py`）

1. 目前進行中且未 PASS 的文法（不會因為看過例句就跳走）。
2. 否則：待加強 → 學習中（依教材順序）→ 未學習（依教材順序）。
3. 已 PASS 的文法**不會**當成新課程，只會以暖身題或混用題出現。
4. 手寫題不會重複；用完後自動由「情境庫＋目標文法」產生新題，並在答對 2 題後要求混用已 PASS 的 N4 文法。
5. 情境會輪替，最近 3 堂課出現過旅行就降低旅行的權重。

## PASS 判定（`progress.py`，數字集中在檔案開頭常數）

同時滿足才 PASS，答對一次不等於 PASS：

* 至少 **2 種不同情境**的獨立正確造句（用了提示、活用練習都不算）。
* 這些正確輸出分布在至少 **2 次不同的練習**中（同一堂答對很多題不算）。
* **最近 2 次**造句都獨立答對。
* 沒有「尚未改正」的核心錯誤（助詞／活用／接續／語意）；反覆出現過（≥2 次）的錯誤要**連續答對 3 次**才算穩定。

錯誤狀態：`active`（尚未改正）→ 連續答對 1 次 `corrected_once`（已改正一次）→ 連續答對 3 次 `stable`（穩定掌握）；再犯一次就回到 `active`。
連續兩題以上（近 4 題內錯 2 題）或有反覆核心錯誤 → 「待加強」。已 PASS 的文法若在別的練習中反覆出錯，會降回「待加強」。

## 批改方式（`grader.py`）— 不只比對唯一標準答案

依序判斷：

1. **錯誤規則**（`data/error_patterns.json`）：確定的錯誤直接抓出並給修正版，例如「なくでも」、「静かだかもしれない」、「食べるのことができる」、「良くなら」。
2. **標準答案／關鍵片段**：與參考答案一致，或必要的文法片段齊全（例如「起きなくてもい」＋「明日」），就接受不同說法與寫法（漢字／假名皆可）。
3. **AI 批改（選用）**：設定 `ANTHROPIC_API_KEY` 後，其餘句子交給 Claude 判斷；它被要求接受所有合理說法，把「更自然的說法」與「真正的錯誤」分開。
   * `export ANTHROPIC_API_KEY=sk-ant-...`（可用 `JPREHAB_AI_MODEL` 指定模型，`--no-ai` 或 `JPREHAB_AI=off` 關閉）。
   * 句子會送到 Anthropic API；沒設定金鑰就不會連網。AI 失敗時自動退回本機批改。
4. **自評**：上面都無法判定時，顯示參考答案與接續規則，由你選「正確／有錯／沒用到目標文法／不太自然」並選錯誤類型。

誠實的限制：沒有 AI 時，自由造句的最後一道判斷是你自己；規則只保證抓到已知錯誤與關鍵片段，無法證明整句沒有任何錯。需要嚴格批改請設定 API 金鑰。

## 資料與備份

| 檔案 | 內容 | 性質 |
|---|---|---|
| `data/grammar.json` | 文法（ID、級別、解釋、接續、例句、對話） | 教材，可手動新增 |
| `data/exercises.json` | 手寫練習題與關鍵片段 | 教材 |
| `data/scenarios.json`、`data/verbs.json`、`data/error_patterns.json` | 情境、活用詞庫、錯誤規則 | 教材 |
| `data/seed_progress.json` | **初始進度**（你目前的 PASS／學習中清單與已知錯誤） | 只在 `init` 時使用 |
| `user_data/progress.json` | 各文法狀態、統計、錯誤追蹤、目前進度 | **你的進度**（每題後原子寫入，並保留 `.bak`） |
| `user_data/history.jsonl` | 逐筆作答（題目、你的答案、修正、錯誤類型）與每堂摘要 | **你的紀錄**（只追加） |

資料不會因關閉程式或重新整理而遺失：寫入先寫暫存檔再替換，主檔損毀時自動讀 `.bak`。
備份只要複製 `user_data/` 資料夾。要把進度放到別台電腦，複製整個資料夾即可；用 `JPREHAB_USER_DIR=/path` 可指定別的資料夾。

### 新增文法

在 `data/grammar.json` 的 `grammar` 陣列中依學習順序加入一筆（欄位見現有項目；例句格式 `[日文, 假名, 繁中, 情境]`），
下次執行會自動以「未學習」加入，既有進度不受影響。沒有手寫題也能練習（會自動產生情境造句題）；
想要更精準的批改，在 `exercises.json` 補題目與 `key_parts`，並在 `error_patterns.json` 補常見錯誤規則。
